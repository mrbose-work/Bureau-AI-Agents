# THE BUREAU
### *All In Order.*

> A bespoke AI-powered Personal Business Operating System built exclusively for Ronit Bose & No-Way.

---

## Overview
The Bureau is a private digital command centre staffed by two AI butlers — **Benjamin** (male, Downton Abbey) and **Bella** (female, classic British lady) — designed to manage every aspect of a modern digital agency with precision, grace, and British elegance.

## Current Version
**v1.0 — Phase 1 Prototype (HTML)**

## Screens
- 🏠 Home Dashboard — Bento grid, morning briefing, quick actions
- 📥 Inbox — Unified messages across Gmail, WhatsApp, LinkedIn, Instagram, Facebook
- 📁 Work — Kanban board + task analytics
- 👥 Clients — Client profiles with revenue sparklines
- 💰 Finance — P&L, subscriptions tracker, credit meters
- 🚀 Growth Hub — No-Way brand performance, market intelligence
- ⚙️ Settings — Butler controls, connected accounts, security

## AI Butlers
- **Benjamin** — Precise, methodical, Downton Abbey butler
- **Bella** — Warm, intuitive, classic British lady
- Powered by **Claude API** (claude-sonnet-4-20250514)
- Voice by **ElevenLabs**

## Tech Stack (Phase 1 Build Target)
- **Frontend:** React 18 + TypeScript + Tailwind CSS + Shadcn/UI
- **Backend:** Node.js + Express.js
- **Database:** Notion API (9 databases)
- **Auth:** Clerk (Google OAuth + PIN + Biometric)
- **Hosting:** Vercel (frontend) + Railway (backend)
- **AI:** Claude API + ElevenLabs + DALL-E 3

## Phase Roadmap

- **Phase 5** Specialist AI agents
- **Phase 6** Full autonomous mode + SaaS potential
