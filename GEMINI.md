# Project Bureau

This project is configured to work with both **Gemini CLI** and **Antigravity CLI**. 

## Unified Agent Instructions
- All agents (Gemini and Antigravity) must follow the standards defined in this workspace.
- Share context across sessions by maintaining this file and the `MEMORY.md` in the agent memory folders.
- Use `agy` for interactive TUI-based collaboration.
- Use `gemini` for surgical CLI edits and background automation.

## Project Structure
- `Bureau App`: The main application codebases.
- `Bureau Business`: Documentation and strategy.
- `Bureau Documents`: Research and recordings.
